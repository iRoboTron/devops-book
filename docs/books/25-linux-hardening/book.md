## Главная идея

Hardening — это не список команд из интернета. Это уменьшение поверхности атаки с проверкой после каждого изменения.

```text
понять угрозу
  -> убрать лишнее
  -> ограничить доступ
  -> проверить
  -> записать как откатить
```

Книга 25 отвечает на вопрос: как укрепить сервер. Книга 26 отвечает на вопрос: как проверить сервер и оформить аудит.

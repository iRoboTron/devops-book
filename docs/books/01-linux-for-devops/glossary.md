# Глоссарий

> Термины и выражения книги «Linux для DevOps». В скобках — главы, где термин вводится или активно используется.

---

**Linux** — семейство свободных Unix-подобных операционных систем; основа большинства серверов и контейнеров. _(глава 1)_

**Дистрибутив** — готовая сборка Linux (ядро + утилиты + менеджер пакетов), например Ubuntu, Debian, CentOS. _(глава 1)_

**Ubuntu Server** — серверный дистрибутив без графики, на котором ведётся обучение в курсе. _(главы 0, 1)_

**Ядро (kernel)** — центральная часть ОС, управляющая железом, процессами и памятью. _(главы 1, 8)_

**Терминал** — текстовый интерфейс для ввода команд. _(глава 1)_

**Shell (оболочка)** — программа, исполняющая твои команды (обычно `bash`). _(главы 1, 12)_

**Команда** — инструкция оболочке: имя программы плюс аргументы и флаги. _(глава 2)_

**Файловая система** — дерево каталогов Linux, начинающееся с корня `/`. _(глава 2)_

**Корень (`/`)** — вершина файловой системы; всё остальное лежит внутри. _(глава 2)_

**Путь** — адрес файла в дереве; абсолютный (от `/`) или относительный (от текущей папки). _(глава 2)_

**`pwd` / `ls` / `cd`** — базовые команды навигации: где я, что здесь, перейти. _(глава 2)_

**Домашняя директория (`~`)** — личная папка пользователя (`/home/имя`). _(главы 2, 9)_

**`pipe` (`|`)** — передача вывода одной команды на вход другой. _(глава 3)_

**Перенаправление (`>`, `>>`)** — запись вывода команды в файл (с заменой или дозаписью). _(главы 3, 12)_

**`find`** — поиск файлов по имени, типу, времени и другим признакам. _(глава 3)_

**Права доступа** — модель «чтение/запись/исполнение» для владельца, группы и остальных. _(глава 4)_

**`chmod`** — изменение прав доступа к файлу (цифрами `755` или буквами `u+x`). _(глава 4)_

**`chown`** — смена владельца и группы файла. _(глава 4)_

**`sudo`** — выполнение команды с правами суперпользователя (root). _(главы 4, 9)_

**root** — суперпользователь с неограниченными правами. _(главы 4, 9)_

**`umask`** — маска, задающая права по умолчанию у новых файлов. _(глава 4)_

**nano / vim** — текстовые редакторы в терминале; nano — простой, vim — мощный. _(глава 5)_

**Процесс** — запущенная программа со своим идентификатором (PID). _(глава 6)_

**PID** — числовой идентификатор процесса. _(глава 6)_

**`ps` / `top` / `htop`** — просмотр запущенных процессов и нагрузки. _(глава 6)_

**`kill` / сигнал** — отправка процессу сигнала (например `SIGTERM`, `SIGKILL`) для остановки. _(глава 6)_

**Фоновая задача (`&`, `nohup`)** — процесс, продолжающий работать после закрытия терминала. _(глава 6)_

**`nice` / приоритет** — управление приоритетом процесса для планировщика. _(глава 6)_

**tmux** — мультиплексор терминала: несколько сессий в одном окне, сессия живёт после отключения. _(глава 6)_

**systemd** — система инициализации и менеджер сервисов в современных Linux. _(глава 7)_

**`systemctl`** — команда управления сервисами systemd (`start`/`stop`/`status`/`enable`). _(главы 7, 8)_

**`.service`-файл** — описание сервиса для systemd (что запускать, от кого, когда). _(глава 7)_

**Демон (daemon)** — фоновый сервис, работающий без участия пользователя. _(глава 7)_

**`/var/log/`** — каталог, где лежат текстовые логи системы и приложений. _(глава 8)_

**Лог** — журнал событий программы или системы. _(глава 8)_

**`tail -f`** — следить за концом файла лога в реальном времени. _(глава 8)_

**`grep`** — поиск строк по шаблону (в файлах и в выводе команд). _(главы 3, 8)_

**`journalctl`** — просмотр логов systemd (`-u сервис`, `--since`). _(глава 8)_

**`dmesg`** — сообщения ядра (железо, драйверы, OOM). _(глава 8)_

**`logrotate`** — ротация логов: ограничивает их рост, сжимает и удаляет старые. _(глава 8)_

**Алгоритм чтения ошибки** — привычка читать ошибку буквально и сужать круг по слоям (DNS → сеть → TLS → сервис → приложение). _(глава 8)_

**Пользователь / группа** — учётная запись и объединение пользователей для управления правами. _(глава 9)_

**`useradd` / `usermod` / `userdel`** — создание, изменение и удаление пользователей. _(глава 9)_

**SSH** — протокол защищённого удалённого доступа к серверу. _(глава 9)_

**SSH-ключ** — пара ключей (приватный + публичный) для входа без пароля. _(глава 9)_

**`~/.ssh/config`** — файл с настройками SSH-подключений (алиасы хостов, ключи). _(глава 9)_

**IP-адрес** — адрес машины в сети. _(глава 10)_

**Порт** — номер «двери» сервиса на машине (80 — HTTP, 443 — HTTPS, 22 — SSH). _(глава 10)_

**DNS** — система, превращающая доменное имя в IP-адрес. _(глава 10)_

**`ip addr` / `ss`** — просмотр сетевых интерфейсов и открытых портов/соединений. _(глава 10)_

**`ping` / `curl` / `nc`** — проверка доступности, HTTP-запросы и работа с портами. _(глава 10)_

**`ufw`** — простой фронтенд к фаерволу (открыть/закрыть порты). _(глава 10)_

**`df` / `du`** — сколько места на дисках и сколько занимают папки. _(глава 11)_

**`mount` / `/etc/fstab`** — подключение файловых систем вручную и автоматически при загрузке. _(глава 11)_

**`lsblk`** — список блочных устройств (дисков и разделов). _(глава 11)_

**swap** — раздел/файл подкачки: «запасная» память на диске. _(глава 11)_

**Shell-скрипт** — файл с последовательностью команд оболочки. _(глава 12)_

**`set -e`** — режим, при котором скрипт останавливается на первой же ошибке. _(глава 12)_

**Пакетный менеджер (`apt`)** — установка, обновление и удаление программ из репозиториев. _(глава 13)_

**PPA / Snap** — дополнительные источники софта в Ubuntu. _(глава 13)_

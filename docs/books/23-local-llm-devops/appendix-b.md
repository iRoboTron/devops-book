# Приложение B: Чеклист безопасности и диагностики

## Безопасность

- [ ] Ollama слушает только `127.0.0.1` или доступен только через внутреннюю сеть.
- [ ] Порт `11434` закрыт снаружи.
- [ ] Порт `3000` закрыт снаружи, если доступ идёт через Nginx.
- [ ] Open-WebUI требует логин.
- [ ] Первый admin-пользователь создан сразу после запуска.
- [ ] Публичная регистрация отключена, если не нужна.
- [ ] HTTPS или WireGuard используется для доступа.
- [ ] В модель не отправляются приватные ключи, `.env`, токены и дампы.

Как проверить каждый пункт:

```bash
# Ollama слушает только локально
ss -tlnp | grep 11434
# Ожидание: 127.0.0.1:11434

# Порты закрыты снаружи
sudo ufw status | grep -E '11434|3000'
# Ожидание: DENY IN для обоих

# Nginx с HTTPS работает
curl -I https://ai.example.com
# Ожидание: HTTP/2 200
```

## Диагностика

| Что проверить | Команда | Норма |
|---|---|---|
| Ollama API | `curl localhost:11434/api/tags` | JSON со списком моделей |
| WebUI | `curl -I localhost:3000` | HTTP-ответ |
| Логи Ollama | `docker logs ollama --tail=50` | нет постоянных ошибок |
| Диск | `df -h` | есть свободное место |
| RAM | `free -h` | нет постоянного swap-ада |
| Порты | `ss -tlnp` | наружу открыт только нужный порт |
| GPU использование | `nvidia-smi` | ollama в списке процессов |
| Ollama на GPU | `docker logs ollama --tail=30 \| grep -i gpu` | строка "loaded on GPU" |

## Типовые ошибки и быстрые решения

| Симптом | Команда диагностики | Решение |
|---|---|---|
| `connection refused` на 11434 | `systemctl status ollama` | `systemctl start ollama` |
| модель не загружается | `free -h` | выбрать меньшую модель или добавить swap |
| streaming не работает в UI | `sudo nginx -t` | проверить `Upgrade`/`Connection` заголовки и `proxy_read_timeout` |
| Ollama открыт на 0.0.0.0 | `ss -tlnp \| grep 11434` | добавить `OLLAMA_HOST=127.0.0.1` в env |
| GPU не используется | `docker logs ollama --tail=30` | проверить `--gpus all` и nvidia-container-toolkit |
| Open-WebUI не видит Ollama | `docker exec open-webui curl -s http://ollama:11434/api/tags` | исправить `OLLAMA_BASE_URL=http://ollama:11434` |

- Сделать `curl`-запрос.

- Поднять Open-WebUI.
- Настроить Nginx или WireGuard.
- Написать один скрипт автоматизации.

- Описать правила приватности.
- Добавить мониторинг ресурсов и регулярную чистку диска.

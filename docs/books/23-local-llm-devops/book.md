## Для кого эта книга

Для человека, который уже умеет пользоваться Linux, Docker и Nginx, но пока воспринимает ИИ как чужой сайт в браузере. После книги LLM должна стать понятной частью стека: процесс, модель, HTTP API, reverse proxy, логи и ограничения.

Книга не учит обучать модели и не обещает, что локальная LLM заменит сильные облачные модели. Цель проще: поднять свой AI-сервис, безопасно закрыть его от интернета и подключить к своим скриптам.

---

## Главная идея

LLM — это не магия. В практическом смысле это файл модели и сервер, который принимает HTTP-запросы.

```text
Пользователь или скрипт
  -> HTTP API
  -> Ollama
  -> модель на диске
  -> ответ текстом
```

Если ты умеешь деплоить обычный web-сервис, то уже понимаешь большую часть работы: где порт, где логи, как закрыть firewall, как поставить Nginx и как проверить ответ через `curl`.

## Что получится в конце

К концу книги у тебя будет один из двух рабочих вариантов:

- безопасный локальный AI-сервис на своём компьютере или сервере;
- стек Ollama + Open-WebUI + Nginx, доступный через HTTPS и закрытый авторизацией.

Дополнительно ты напишешь bash- и Python-скрипты, которые обращаются к модели через API, и подготовишь чеклист: где лежат модели, как посмотреть логи, как удалить лишнее и как убедиться, что сервис не торчит наружу.

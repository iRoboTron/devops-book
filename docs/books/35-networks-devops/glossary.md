# Глоссарий

> Термины и выражения книги «Сети для DevOps». В скобках — главы, где термин вводится или активно используется.

---

**OSI / TCP/IP** — модели слоёв сети; на практике пользуются стеком TCP/IP (link → internet → transport → application). _(глава 0)_

**IP-адрес** — адрес узла в сети (IPv4 `192.168.1.10`, IPv6). _(главы 0, 1)_

**Подсеть / маска** — деление сети на части; маска отделяет «сеть» от «хоста». _(глава 1)_

**CIDR** — запись подсети вида `/24`, указывающая число бит сетевой части. _(глава 1)_

**Шлюз (gateway)** — узел, через который трафик уходит в другие сети. _(главы 1, 2)_

**`ip addr` / `ip route` / `ip link`** — просмотр и настройка интерфейсов, маршрутов и линков в Linux. _(глава 2)_

**Сетевой интерфейс** — точка подключения к сети (`eth0`, `wlan0`, `lo`). _(глава 2)_

**TCP** — надёжный протокол с установлением соединения и подтверждениями. _(глава 3)_

**UDP** — быстрый протокол без гарантий доставки (DNS, видео, игры). _(глава 3)_

**Порт** — номер сервиса на узле (80, 443, 22). _(глава 3)_

**Сокет** — пара IP:порт, идентифицирующая соединение. _(глава 3)_

**Трёхстороннее рукопожатие (handshake)** — установка TCP-соединения (SYN → SYN-ACK → ACK). _(глава 3)_

**Состояния TCP** — `LISTEN`, `ESTABLISHED`, `TIME_WAIT` и др. _(глава 3)_

**DNS** — система, превращающая доменное имя в IP-адрес. _(глава 4)_

**Записи DNS** — `A`/`AAAA` (IP), `CNAME` (алиас), `MX` (почта), `TXT`, `NS`. _(глава 4)_

**Рекурсивный / авторитативный DNS** — резолвер, который ищет ответ, и сервер, который владеет зоной. _(глава 4)_

**TTL** — время кэширования DNS-записи. _(глава 4)_

**HTTP** — протокол веба: запрос (метод, путь, заголовки) и ответ (код, заголовки, тело). _(глава 5)_

**HTTP-методы** — `GET`, `POST`, `PUT`, `DELETE` и др. _(глава 5)_

**Коды ответов** — `2xx` успех, `3xx` редирект, `4xx` ошибка клиента, `5xx` ошибка сервера. _(глава 5)_

**HTTPS** — HTTP поверх TLS (шифрование + аутентификация сервера). _(глава 6)_

**TLS** — протокол шифрования канала; преемник SSL. _(глава 6)_

**Сертификат / CA** — подтверждение подлинности домена, выданное центром сертификации. _(глава 6)_

**`openssl`** — утилита для работы с сертификатами и TLS-диагностики. _(глава 6)_

**`ping`** — проверка достижимости узла (ICMP). _(глава 7)_

**`traceroute` / `mtr`** — путь пакета по маршрутизаторам и потери на нём. _(глава 7)_

**`ss`** — просмотр сокетов и открытых портов (замена `netstat`). _(глава 7)_

**`tcpdump` / Wireshark** — захват и анализ сетевых пакетов. _(глава 7)_

**`nmap`** — сканер портов и инвентаризация хостов в сети. _(глава 8)_

**iptables** — фаервол Linux: правила в цепочках (`INPUT`, `FORWARD`, `OUTPUT`). _(глава 9)_

**NAT / MASQUERADE** — подмена адресов; выход множества хостов через один внешний IP. _(глава 9)_

**Docker bridge / host / overlay** — сетевые драйверы Docker для контейнеров. _(глава 10)_

**Network namespace / veth** — изоляция сети процесса и виртуальная пара интерфейсов. _(глава 10)_

**CNI** — плагин сети Kubernetes между Pod'ами (Flannel/Calico/Cilium). _(глава 11)_

**Service / Ingress (K8s)** — стабильный адрес для Pod'ов и HTTP-маршрутизация снаружи. _(глава 11)_

**MTU** — максимальный размер пакета; неверный MTU ломает «тяжёлые» соединения. _(главы 7, 10)_

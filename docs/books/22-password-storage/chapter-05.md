# Глава 5: Bitwarden как практичный старт

> **Запомни:** Bitwarden — хороший старт для многих, но даже хороший менеджер паролей нужно настроить с MFA, backup и recovery.

---

## 5.1 Почему именно Bitwarden в этой книге

Bitwarden выбран как основной практический пример не потому, что другие варианты плохие.

Причины:

- есть бесплатный уровень;
- есть приложения для разных платформ;
- есть browser extension;
- есть мобильное приложение;
- есть генератор паролей;
- есть secure notes;
- есть family/team возможности;
- его легко объяснить новичку.

Если ты выберешь 1Password, Proton Pass или другой менеджер, логика останется похожей.

---

## 5.2 Что мы настраиваем

Минимальная схема:

```text
Bitwarden account
  -> сильный мастер-пароль
  -> MFA на сам Bitwarden
  -> browser extension
  -> mobile app
  -> первые записи
  -> backup/export
  -> recovery plan
```

Не начинай с переноса всех аккаунтов. Сначала настрой саму систему.

---

## 5.3 Создание аккаунта

### Шаг 1: открой сайт Bitwarden

Сайт: **bitwarden.com**

На главной странице нажми «Get Started Free» или «Создать аккаунт».

### Шаг 2: введи email

Используй основную почту или тот email, который хорошо защищён.

Этот email будет логином. Если потеряешь к нему доступ — потеряешь и возможность восстановить Bitwarden-аккаунт.

### Шаг 3: придумай мастер-пароль

Это главный шаг. Не торопись.

Требования:
- длина от 16 символов;
- passphrase из случайных слов или длинная комбинация;
- нигде раньше не использовался;
- ты можешь ввести его без ошибок несколько раз подряд.

Проверь себя до регистрации: закрой эту книгу, подожди 5 минут, попробуй написать пароль в блокноте. Если ошибся — придумай другой, более запоминаемый. Потом удали этот тест.

Примеры учебных форматов (не используй их буквально):

```text
orbit-planet-snow-window-83
```

```text
coffee-brick-lamp-river-49
```

### Шаг 4: заполни подсказку к мастер-паролю

Подсказка видна тебе на экране входа. Её цель — напомнить формат, а не раскрыть пароль.

Плохая подсказка:

```text
имя кота + год рождения
```

Хорошая подсказка:

```text
5 слов мой любимый формат
```

Подсказка описывает схему, но не само содержимое.

### Шаг 5: подтверди email

Bitwarden отправит письмо. Найди его и перейди по ссылке для подтверждения.

После этого vault создан. Помни: Bitwarden не хранит твой мастер-пароль и не может его восстановить. Если забудешь — потеряешь доступ к хранилищу.

## 5.4 MFA на Bitwarden

Менеджер паролей — критичный аккаунт. MFA здесь обязательна.

### Шаг 1: поставь TOTP-приложение на телефон

Выбери одно:

| Приложение | Платформа | Особенность |
|---|---|---|
| **Aegis** | Android | Бесплатный, умеет backup кодов |
| **2FAS** | Android и iOS | Бесплатный, умеет backup |
| **Google Authenticator** | Android и iOS | Простой, но без backup — опасно |
| **Microsoft Authenticator** | Android и iOS | Удобный, есть backup |

Рекомендация для новичка: **Aegis** (Android) или **2FAS** (любой телефон) — у них есть функция backup кодов, что важно на случай потери телефона.

### Шаг 2: включи MFA в Bitwarden

1. Войди на **bitwarden.com**;
2. В правом верхнем углу нажми на иконку аккаунта;
3. Выбери «Account Settings»;
4. Перейди в «Security» → «Two-step Login»;
5. Напротив строки «Authenticator App» нажми «Manage»;
6. Введи мастер-пароль для подтверждения;
7. Появится QR-код.

### Шаг 3: отсканируй QR-код

Открой TOTP-приложение на телефоне.

Нажми «+» или «Добавить аккаунт» → «Отсканировать QR».

Наведи камеру на QR-код на экране. В приложении появится запись «Bitwarden» с 6-значным кодом, который обновляется каждые 30 секунд.

### Шаг 4: введи код и сохрани подтверждение

Введи текущий 6-значный код из приложения в поле на сайте Bitwarden. Нажми «Enable».

### Шаг 5: сохрани recovery code — самое важное

Bitwarden покажет recovery code. Это длинная строка вроде:

```text
XXXX-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX
```

Это аварийный ключ — он нужен, если телефон потеряется и TOTP-код станет недоступен.

**Куда положить:**
- распечатай и убери в папку с документами;
- или перепиши на бумагу и убери в безопасное место;
- не оставляй только в Downloads или в чате с собой.

**Чего не делать:**
- не храни recovery code только внутри самого Bitwarden — это замкнутый круг.

```text
Потерял телефон
  → нужен код Bitwarden, чтобы войти
  → код хранился в Bitwarden
  → войти в Bitwarden нельзя без кода
```

### Шаг 6: проверь, что MFA работает

Выйди из Bitwarden в браузере полностью.

Войди заново: email → мастер-пароль → 6-значный код из телефона.

Если получилось — MFA настроена правильно.

---

**Что лучше не делать:**

- не храни TOTP для Bitwarden внутри того же Bitwarden;
- не используй SMS как MFA для менеджера паролей, если есть возможность TOTP.

## 5.5 Browser extension

Расширение — это основной способ пользоваться Bitwarden каждый день: автозаполнение, сохранение новых логинов, генерация паролей прямо на сайте.

### Шаг 1: установи расширение из официального источника

**Chrome / Chromium / Edge / Brave:**
1. Открой Chrome Web Store (chromewebstore.google.com);
2. Ищи «Bitwarden»;
3. Официальное расширение — от разработчика **Bitwarden Inc.**, с синей иконкой замка;
4. Нажми «Добавить в Chrome».

**Firefox:**
1. Открой Firefox Browser Add-ons (addons.mozilla.org);
2. Ищи «Bitwarden»;
3. Официальное расширение — от разработчика **Bitwarden Inc.**;
4. Нажми «Добавить в Firefox».

**Важно:** не ставь расширения с похожими названиями от неизвестных авторов. Проверяй имя разработчика перед установкой.

### Шаг 2: войди в расширение

После установки появится иконка Bitwarden в панели браузера.

1. Нажми на иконку;
2. Введи email;
3. Введи мастер-пароль;
4. Введи 6-значный код из TOTP-приложения.

### Шаг 3: настрой блокировку

В расширении: нажми иконку → Settings → «Vault Timeout».

Поставь одно из:
- **«On Browser Restart»** — разблокировка при каждом запуске браузера;
- **«15 minutes»** — блокировка после простоя.

Не выбирай **«Never»** — это значит, что кто угодно, кто откроет твой браузер, получит доступ ко всем паролям.

### Шаг 4: проверь автозаполнение

Зайди на любой сайт с формой входа.

Нажми на поле логина — должно появиться предложение Bitwarden подставить данные.

Или нажми на иконку Bitwarden в панели браузера и найди нужный сайт поиском.

Если запись в Bitwarden привязана к правильному URL — она подставится. Если URL другой — не подставится. Это защита от фишинга.

## 5.6 Mobile app

Мобильное приложение нужно для:

- входа в приложения;
- доступа к паролям без компьютера;
- быстрого поиска;
- иногда для passkeys или MFA, если ты так решил.

Настройки:

- включи блокировку приложения;
- используй PIN/биометрию только как unlock;
- помни мастер-пароль;
- проверь, что телефон сам защищён PIN/паролем.

---

## 5.7 Первые записи

Начни с тестовых записей:

```text
demo-email@example.com
demo-shop@example.com
demo-github@example.com
```

Поля записи:

- name;
- username/email;
- password;
- URI;
- notes;
- folder.

URI важен. Именно он помогает менеджеру понять, на каком сайте можно подставлять пароль.

## 5.8 Папки и организация

Не усложняй.

Для личного vault обычно хватает:

- Critical;

Сначала защити критичное. Красота папок потом.

## 5.9 Secure notes

Secure note можно использовать для:

- recovery codes;
- инструкции восстановления;
- номера лицензии;
- заметки по домену;
- списка шагов при потере телефона.

Но не превращай secure notes в мусорную корзину.

Для каждой заметки спроси:

> Если это увидит человек с доступом к vault, что он сможет сделать?

Если ответ "получит полный контроль над моей жизнью", подумай о дополнительной защите или отдельном хранении.

---

## 5.10 Export и backup

Bitwarden умеет export.

Разница:

- plain export — удобно, но опасно;
- encrypted export — безопаснее, но зависит от формата и восстановления.

Для учебной практики делай export только тестового vault.

Для реального backup:

- изучи формат;
- выбери защищённое место хранения;
- проверь восстановление;
- удали временные plain-файлы;
- не оставляй export в `Downloads`.

## 5.11 Практика: настройка тестового Bitwarden

### Задача 1: подготовка

Создай тестовые записи, не реальные:

```text
Demo Mail
Demo Shop
Demo GitHub
Demo Router
Demo Wi-Fi
```

### Задача 2: генератор

Для каждой записи сгенерируй пароль:

- минимум 16 символов;
- случайный;
- уникальный.

Не пытайся его запомнить.

### Задача 3: URI

Добавь URI:

```text
https://example.com
https://github.com
http://router.local
```

Проверь, что запись не подставляется на неправильном домене.

### Задача 4: lock

Настрой блокировку:

- после закрытия браузера;
- после простоя;
- при блокировке компьютера, если доступно.

### Задача 5: тестовый export

Сделай export тестовых данных.

Потом:

1. найди файл;
2. открой и пойми, насколько он чувствителен;
3. удали файл;
4. очисти корзину;
5. запиши вывод.

## 5.12 Первая реальная миграция

> **Подожди до главы 8.** Когда будешь переносить реальные аккаунты, ты захочешь сразу включить MFA. Если пропустить этот шаг, придётся возвращаться к каждому аккаунту повторно. Пока потренируйся на тестовых данных, а к реальной миграции вернись после главы 8.

Если не терпится — можно начать с самого низкорискового аккаунта (старый форум без важных данных), но главные аккаунты — только после MFA.

Выбери один неважный реальный аккаунт.

Например:

- старый магазин;
- учебный сервис;
- форум.

Сделай:

1. найди аккаунт;
2. проверь email восстановления;
3. сгенерируй новый пароль;
4. поменяй пароль на сайте;
5. сохрани запись в Bitwarden;
6. выйди;
7. войди заново через менеджер.

Не начинай с банка или основной почты. Сначала отработай движение на низком риске.

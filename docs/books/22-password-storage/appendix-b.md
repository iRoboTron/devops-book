# Приложение B: Чеклисты MFA, recovery и backup

> **Назначение:** быстрые проверки, которые можно использовать раз в несколько месяцев.

---

## B.1 Чеклист первой настройки

- [ ] Выбран менеджер паролей
- [ ] Создан сильный мастер-пароль
- [ ] Мастер-пароль не используется нигде ещё
- [ ] Включён lock timeout
- [ ] Установлен browser extension
- [ ] Установлено мобильное приложение
- [ ] Созданы тестовые записи
- [ ] Проверено автозаполнение
- [ ] Включён MFA на менеджере
- [ ] Recovery code менеджера сохранён

---

## B.2 Чеклист критичного аккаунта

Для каждого критичного аккаунта:

- [ ] Пароль уникальный
- [ ] Пароль хранится в менеджере
- [ ] MFA включён
- [ ] Recovery codes сохранены
- [ ] Backup email актуален
- [ ] Backup phone актуален, если используется
- [ ] Активные сессии проверены
- [ ] Старые приложения с доступом проверены
- [ ] Есть план восстановления

---

## B.3 Чеклист MFA

- [ ] Тип MFA понятен
- [ ] Recovery codes сохранены
- [ ] Recovery codes не лежат только на телефоне
- [ ] Есть запасной способ входа
- [ ] TOTP-приложение имеет backup
- [ ] Push не подтверждается автоматически
- [ ] Hardware key имеет запасной вариант
- [ ] Потеря телефона смоделирована

---

## B.4 Чеклист recovery

- [ ] Есть recovery kit
- [ ] Известно, где recovery codes
- [ ] Известно, где backup vault
- [ ] Известно, что делать при потере телефона
- [ ] Известно, что делать при потере ноутбука
- [ ] Backup email защищён
- [ ] Trusted contact понятен, если нужен
- [ ] Emergency access настроен, если нужен
- [ ] Дата последней проверки записана

---

## B.5 Чеклист backup

- [ ] Backup создан
- [ ] Формат backup понятен
- [ ] Plain export не оставлен в Downloads
- [ ] Backup защищён
- [ ] Backup хранится отдельно
- [ ] Restore проверен
- [ ] Дата backup записана
- [ ] Следующая проверка запланирована

---

## B.6 Чеклист потери телефона

1. Заблокировать телефон удалённо.
2. Войти в почту с доверенного устройства.
3. Проверить активные сессии.
4. Войти в менеджер паролей.
5. Использовать recovery codes для MFA.
6. Подключить новый телефон.
7. Отключить старое устройство.
8. Пересоздать MFA там, где нужно.
9. Проверить банк, почту, GitHub, мессенджеры.
10. Обновить recovery kit.

- [ ] Старые SSH keys удалены

- [ ] MFA обязательно

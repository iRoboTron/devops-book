# Приложение A: Шпаргалка «хочу → инструмент»

Найди свою задачу в левой колонке — в правой увидишь дефолтный инструмент и куда идти дальше. Таблица отсортирована по частоте запроса: самые типичные задачи — сверху. Если нужны детали выбора — в каждой главе есть дерево решений «Как выбрать за 30 секунд».

---

| Хочу… | Инструмент (см.) |
|---|---|
| Дать себе доступ к домашнему серверу из кафе | Tailscale (гл. 1) |
| Пробросить локальный порт в интернет для демо | Cloudflare Tunnel (гл. 1) |
| Запускать приложения в контейнерах | Docker Compose / Podman Compose (гл. 6, книга 03 / книга 33) |
| HTTPS на сайт без возни с сертификатами | Caddy (гл. 2, книга 02) |
| Автодеплой при push в Git | GitHub Actions (гл. 6, книга 04) |
| Знать, когда сервер или сайт упал | Uptime Kuma + ntfy (гл. 3) |
| Хранить пароли команды | Vaultwarden (гл. 4, книга 22) |
| Смотреть метрики CPU / RAM / диска | Netdata (homelab) или Prometheus + Grafana (гл. 3, книга 38) |
| Бэкап, который реально восстановится | restic + правило 3-2-1 (гл. 5) |
| Настроить reverse proxy для нескольких приложений | Nginx Proxy Manager (homelab, мышкой) или Traefik (если уже есть Docker) (гл. 2) |

| Дать доступ команде к серверам без VPN-сервера | Tailscale (гл. 1) |

| Поднять инфраструктуру кодом | Terraform / OpenTofu (гл. 6, книга 08) |

| Создать чат-бота по своей документации | Ollama + Qdrant + Dify (гл. 7) |

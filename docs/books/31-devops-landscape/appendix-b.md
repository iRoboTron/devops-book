# Приложение B: Алфавитный указатель инструментов

Все инструменты, упомянутые в книге, в алфавитном порядке — с кратким функциональным описанием и номером главы где инструмент рассматривается.

---

**AdGuard Home** — self-hosted DNS-сервер с блокировкой рекламы и трекеров на уровне DNS для всей домашней сети. Гл. 1.

**Alertmanager** — компонент экосистемы Prometheus: принимает алерты, группирует их, подавляет дубликаты и маршрутизирует в нужные каналы уведомлений. Гл. 3.

**Ansible** — agentless-инструмент конфигурирования серверов: подключается по SSH и применяет YAML-плейбуки к одной или нескольким машинам без установки агентов. Гл. 6.

**Authelia** — лёгкий MFA-прокси перед reverse proxy: добавляет двухфакторную аутентификацию к любому приложению за Nginx или Traefik без полноценного IdP. Гл. 4.

**Authentik** — self-hosted Identity Provider с визуальным конструктором flows: поддерживает OAuth2, OIDC, SAML, MFA, LDAP и управление группами. Гл. 4.

**Bitwarden** — облачный менеджер паролей с бесплатным личным аккаунтом и платным командным тарифом; официальные клиенты совместимы с self-hosted Vaultwarden. Гл. 4.

**BorgBackup** — инкрементальный бэкап-инструмент с дедупликацией и сжатием для Linux и macOS через SSH; нет нативного клиента Windows. Гл. 5.

**BunkerWeb** — Nginx с встроенным WAF на базе ModSecurity, rate limiting и фильтрацией ботов; защита из коробки без ручной настройки ModSecurity. Гл. 2.

**Caddy** — reverse proxy и веб-сервер с автоматическим получением и обновлением TLS-сертификатов Let's Encrypt; конфигурируется декларативным Caddyfile. Гл. 2.

**Casdoor** — Go-based Identity Provider с поддержкой OAuth2, OIDC, SAML и социальных провайдеров; по функциональности между Authelia и Keycloak. Гл. 4.

**ClickHouse** — колоночная OLAP-база данных для аналитических запросов по миллиардам строк; не поддерживает транзакционные UPDATE/DELETE, не заменяет PostgreSQL. Гл. 5.

**Cloudflare Tunnel** — SaaS-сервис для публикации локальных сервисов через инфраструктуру Cloudflare без открытых портов и белого IP. Гл. 1.

**Codeium / Windsurf** — SaaS-плагин автодополнения кода для VS Code и JetBrains; бесплатная альтернатива GitHub Copilot для inline-подсказок в редакторе. Гл. 7.

**Dify** — self-hosted платформа для сборки RAG-приложений и AI-workflow: веб-UI, загрузка документов, конструктор pipeline, интеграция с Ollama и Qdrant. Гл. 7.

**ELK Stack** — набор Elasticsearch + Logstash + Kibana для централизованного сбора, хранения и full-text поиска по логам; требует 4+ ГБ RAM. Гл. 3.

**Forgejo** — лёгкий self-hosted Git-хостинг (форк Gitea): репозитории, issues, pull requests, webhooks, CI-интеграция; потребляет ~100–150 МБ RAM. Гл. 6.

**frp** — self-hosted обратный туннель через собственный сервер-посредник: проксирует TCP/UDP/HTTP, требует VPS как relay-сервер. Гл. 1.

**Garage** — распределённый self-hosted S3-совместимый объектный storage на Rust: сохраняет доступ к данным при потере одного узла в кластере из 3+ машин. Гл. 5.

**Gatus** — self-hosted инструмент мониторинга статуса сервисов с поддержкой HTTP/TCP/DNS/ICMP-проверок и встроенной статус-страницей. Гл. 3.

**GitHub Actions** — встроенная SaaS CI/CD-система GitHub: пайплайны в YAML-файлах, тысячи готовых actions в маркетплейсе, бесплатный лимит для публичных репозиториев. Гл. 6.

**GitLab CI** — встроенная CI/CD-система GitLab: конфигурация в `.gitlab-ci.yml`, полный цикл тест/build/deploy, работает в облачном и self-hosted GitLab. Гл. 6.

**HAProxy** — балансировщик нагрузки L4/L7 с поддержкой sticky sessions, ACL, health checks и zero-downtime деплоя; выбор для enterprise с несколькими backend-пулами. Гл. 2.

**Headscale** — self-hosted координатор для Tailscale-клиентов: убирает зависимость от Tailscale-облака, сохраняет совместимость с официальными клиентами. Гл. 1.

**Infisical** — open-source менеджер секретов для приложений с веб-UI, SDK для Python/Node/Go и интеграцией с Kubernetes через Operator; развёртывается одним Docker Compose. Гл. 4.

**Jan** — self-hosted десктопное приложение с графическим интерфейсом для запуска и общения с локальными LLM-моделями без командной строки. Гл. 7.

**Jaeger** — инструмент распределённой трассировки запросов через цепочки микросервисов; нужен только при наличии 10+ взаимодействующих сервисов. Гл. 3.

**k3s** — облегчённый дистрибутив Kubernetes: один бинарник, менее 512 МБ RAM, полный K8s API; стандарт для homelab и облегчённого production. Гл. 6.

**KeepHQ** — open-source платформа управления алертами и инцидентами: эскалации, расписания дежурств, интеграция с Alertmanager и Grafana; open-source альтернатива PagerDuty. Гл. 3.

**KeePassXC** — локальный менеджер паролей: хранит данные в зашифрованном `.kdbx`-файле без сервера; только для одного человека без синхронизации. Гл. 4.

**Keycloak** — enterprise Identity Provider от Red Hat с полной поддержкой LDAP, Active Directory, SAML 2.0 и fine-grained RBAC; требовательнее к ресурсам чем Authentik. Гл. 4.

**Kopia** — инструмент бэкапа с дедупликацией на уровне блоков, веб-UI и десктопным приложением для Windows, macOS и Linux. Гл. 5.

**Loki** — система хранения логов Grafana Labs: индексирует только метаданные, хранит строки дёшево; запросы через LogQL, визуализация в Grafana. Гл. 3.

**MinIO** — self-hosted объектный storage с S3-совместимым API в одном Docker-контейнере: версионирование, lifecycle policies, event notifications. Гл. 5.

**NetBird** — полностью self-hosted mesh-VPN-стек: координатор, веб-UI и relay на своём железе; для сценариев когда Tailscale-облако неприемлемо. Гл. 1.

**Netdata** — агент мониторинга с нулевой конфигурацией: тысячи метрик из коробки, встроенный веб-UI; для homelab и быстрого старта без Prometheus. Гл. 3.

**Nginx** — веб-сервер и reverse proxy: стандарт де-факто с тысячами готовых конфигов, интеграцией с Let's Encrypt через certbot и поддержкой виртуальных хостов. Гл. 2.

**Nginx Proxy Manager** — веб-GUI поверх Nginx: добавление proxy hosts, SSL через Let's Encrypt и базовая аутентификация без написания конфигов вручную. Гл. 2.

**ngrok** — SaaS обратный туннель: один бинарник, секунда до публичного URL; бесплатного тарифа достаточно для разовых демо и webhook-отладки. Гл. 1.

**Nomad** — оркестратор рабочих нагрузок из HashiCorp-стека: работает рядом с Vault и Consul; нишевый выбор для тех кто уже в HashiCorp-экосистеме. Гл. 6.

**Ollama** — инструмент запуска LLM локально одной командой: поддерживает десятки моделей, предоставляет OpenAI-совместимый API для подключения к Aider, Continue и другим инструментам. Гл. 7.

**Open WebUI** — self-hosted браузерный чат-интерфейс для Ollama: хранит историю разговоров локально, поддерживает несколько моделей одновременно. Гл. 7.

**OpenSearch** — open-source поисковый движок (форк Elasticsearch): используется для full-text поиска по логам и аналитики по большим объёмам данных. Гл. 3.

**OpenTelemetry Collector** — vendor-neutral агент сбора метрик, логов и трейсов: промежуточный слой для доставки телеметрии в несколько систем одновременно. Гл. 3.

**OpenTofu** — open-source форк Terraform с полной совместимостью синтаксиса HCL: рекомендованный выбор для новых проектов после смены лицензии HashiCorp в 2023 году. Гл. 6.

**Passbolt** — self-hosted командный менеджер паролей с шифрованием на стороне клиента, командными папками и управлением правами доступа через веб-интерфейс. Гл. 4.

**Podman** — контейнерный runtime без привилегированного демона: запускает контейнеры rootless, совместим с Docker CLI, стандарт на RHEL/CentOS Stream 9+. Гл. 6.

**PostgreSQL** — реляционная СУБД с транзакциями ACID, JSONB, полнотекстовым поиском и экосистемой расширений; дефолтный выбор для веб-приложений и API. Гл. 5.

**Prometheus** — система мониторинга с pull-моделью сбора метрик через HTTP endpoint'ы, локальным хранением временных рядов и языком запросов PromQL. Гл. 3.

**Qdrant** — self-hosted векторная база данных для хранения embeddings и семантического поиска; используется как хранилище в RAG-системах поверх Ollama и Dify. Гл. 7.

**RAGFlow** — self-hosted платформа для RAG по документам: специализируется на PDF, Markdown и Confluence; проще Dify если нужен только RAG без workflow-автоматизации. Гл. 7.

**Redis** — in-memory хранилище данных для кэша, сессий, pub/sub и очередей задач; не используется как основная реляционная БД. Гл. 5.

**restic** — инструмент бэкапа с дедупликацией и шифрованием по умолчанию: поддерживает S3, SFTP, Backblaze B2 и локальный диск; один бинарник без зависимостей. Гл. 5.

**SQLite** — встраиваемая реляционная БД в один файл без отдельного сервера; подходит для небольших приложений без высокой конкурентности записей. Гл. 5.

**Tailscale** — SaaS mesh-VPN на базе WireGuard: объединяет устройства за NAT в единую сеть с MagicDNS, настройка за 5 минут без своего сервера-координатора. Гл. 1.

**Terraform** — декларативный инструмент провизионирования облачной инфраструктуры через HCL: описываешь конечное состояние, инструмент рассчитывает план изменений. Гл. 6.

**Traefik** — reverse proxy с автообнаружением сервисов через Docker labels и Kubernetes annotations: встроенный Let's Encrypt, динамическая маршрутизация без перезапуска. Гл. 2.

**Uptime Kuma** — self-hosted мониторинг доступности сервисов: HTTP/TCP/DNS/Docker-проверки, 90+ каналов уведомлений, статус-страница; всё в одном контейнере. Гл. 3.

**Vault (HashiCorp)** — платформа управления секретами: dynamic secrets, AppRole, Kubernetes-интеграция через Vault Agent Injector, полный audit trail выдачи секретов. Гл. 4.

**Vaultwarden** — self-hosted Rust-реализация сервера Bitwarden: ~20 МБ RAM, полностью совместима со всеми официальными Bitwarden-клиентами (браузер, мобильник, CLI). Гл. 4.

**Vector** — высокопроизводительный агент сбора, трансформации и маршрутизации логов и метрик на Rust; альтернатива Promtail/Fluentd когда нужны трансформации данных на лету. Гл. 3.

**VictoriaMetrics** — PromQL-совместимая система хранения метрик: потребляет в 3–5 раз меньше RAM чем Prometheus при тех же данных; замена Prometheus без изменения запросов. Гл. 3.

**WireGuard** — VPN-протокол: минимальный код, высокая производительность, шифрование на уровне ядра Linux; лежит в основе Tailscale, Headscale и NetBird. Гл. 1.

**Woodpecker CI** — лёгкий self-hosted CI-сервер: совместим с Forgejo и Gitea через webhooks, конфигурация в `.woodpecker.yml`, минимальное потребление ресурсов. Гл. 6.

**ZeroTier** — self-hosted виртуальная Layer-2 сеть с поддержкой broadcast и multicast; выбор когда приложению нужно сетевое вещание, которое Tailscale не поддерживает. Гл. 1.

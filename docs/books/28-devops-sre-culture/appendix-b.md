# Приложение B: Ресурсы и дальнейшее чтение

Эти материалы не обязательны для старта, но полезны, если тема DevOps/SRE зацепила.

## Google SRE Book

Бесплатная онлайн-книга от Google про SRE. Читать выборочно:

- toil;
- SLO;
- monitoring;
- postmortem.

Не надо копировать всё буквально. Google решает задачи масштаба Google.

## DORA State of DevOps Report

Ежегодные отчёты про delivery-метрики и практики команд. Полезно для понимания, почему DORA-метрики вообще появились.

## Accelerate

Книга Nicole Forsgren, Jez Humble, Gene Kim. Объясняет исследовательскую базу DORA-метрик.

## Проект Феникс

Художественная книга про DevOps-трансформацию. Хорошо показывает конфликт разработки, эксплуатации и бизнеса.

## CNCF Glossary

Словарь облачных терминов. Полезен, если встречаешь слова вроде observability, service mesh, deployment, rollout.

## Как читать дальше

Не пытайся читать всё подряд. Выбирай по проблеме:

| Проблема | Что читать |
|---|---|
| много ручной работы | SRE Book про toil |
| непонятна надёжность | SLO/error budget |
| хаос с релизами | Accelerate/DORA |
| конфликт Dev и Ops | Проект Феникс |
| термины непонятны | CNCF Glossary |

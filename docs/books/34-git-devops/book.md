## Главная идея

Git — это не просто «сохранение версий». Это язык на котором инженеры разговаривают об изменениях в коде, инфраструктуре и конфигурации.

```text
Без Git:
config-v1.yml, config-v2.yml, config-FINAL.yml, config-FINAL2.yml...
"Кто поменял nginx в пятницу?" — никто не знает.
"Верни как было" — вручную, по памяти.

С Git:
git log --oneline nginx.conf   ← кто, когда, зачем
git revert abc1234             ← откатить конкретное изменение
git diff main feature/tls      ← сравнить ветки перед деплоем
```

Ansible-плейбуки, Terraform-конфиги, Kubernetes-манифесты, Dockerfile — всё это код. Код живёт в Git. CI/CD читает Git. Ревью происходит в Git. Если не знать Git уверенно — всё остальное в DevOps будет сложнее.

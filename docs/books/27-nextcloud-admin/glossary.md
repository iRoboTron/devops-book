# Глоссарий

> Термины и выражения книги «Администрирование Nextcloud». В скобках — главы, где термин вводится или активно используется.

---

**Nextcloud** — self-hosted платформа для хранения и синхронизации файлов, календарей, контактов и совместной работы. Эта книга — про администрирование уже работающей установки. _(главы 0, 1)_

**Nextcloud AIO (All-In-One)** — официальный способ развёртывания Nextcloud набором Docker-контейнеров под управлением mastercontainer. _(главы 0, 2)_

**mastercontainer** — контейнер `nextcloud-aio-mastercontainer`, который запускает, останавливает и обновляет остальные контейнеры AIO; «шеф-повар» всей связки. _(глава 0)_

**nextcloud-aio-nextcloud** — основной контейнер приложения, где работают PHP, ядро Nextcloud и команда `occ`. _(главы 0, 1)_

**nextcloud-aio-database** — контейнер PostgreSQL, хранящий метаданные Nextcloud. _(главы 0, 4)_

**nextcloud-aio-redis** — контейнер Redis для кэша и file locking. _(главы 0, 6)_

**occ** — консольная утилита администрирования Nextcloud (`occ` = ownCloud Console) для статуса, приложений, пользователей, индексов и обслуживания. _(главы 1, приложение A)_

**www-data** — системный пользователь веб-сервера, под которым должны выполняться `occ` и файлы Nextcloud; запуск под root портит права. _(главы 1, 8)_

**maintenance mode** — режим обслуживания: Nextcloud отдаёт страницу-заглушку и блокирует обычные команды; включается перед консистентным бэкапом и обновлением. _(главы 1, 2, 5)_

**maintenance:repair** — команда `occ`, запускающая внутренние ремонтные шаги после обновлений и сбоев. _(главы 1, 2, 4)_

**app (приложение)** — модуль Nextcloud (calendar, deck, notes и т.п.); управляется через `occ app:*` и может ломать систему не хуже обновлений ядра. _(глава 3)_

**shipped app** — приложение, поставляемое вместе с Nextcloud; видно через `occ app:list --shipped`. _(глава 3)_

**несовместимость приложения** — ситуация, когда после обновления ядра приложение вызывает ошибки PHP; лечится отключением (`app:disable`) и поиском совместимой версии. _(глава 3)_

**core (ядро)** — сам Nextcloud без приложений; его обновление рискованнее обновления отдельного app. _(глава 2)_

**release notes** — официальное описание изменений версии; читается перед обновлением ядра. _(глава 2)_

**needsDbUpgrade** — флаг в `occ status`, означающий, что схема БД требует обновления (`occ upgrade`). _(глава 2)_

**occ upgrade** — команда, завершающая обновление ядра, когда БД требует миграции. _(глава 2)_

**PostgreSQL** — реляционная СУБД, в которой Nextcloud хранит метаданные: пользователей, настройки, filecache, шары, блокировки. _(глава 4)_

**метаданные** — данные о файлах (владелец, путь, размер, доступ), хранящиеся в БД отдельно от самих файлов. _(глава 4)_

**data directory** — каталог с самими файлами пользователей (в AIO смонтирован как `/mnt/ncdata`); хранит байты, но не метаданные. _(главы 0, 4, 5)_

**psql** — клиент командной строки PostgreSQL для подключения к базе Nextcloud. _(глава 4)_

**oc_filecache** — таблица БД с кэшем файлов (путь, размер, владелец каждого файла). _(глава 4)_

**db:add-missing-indices** — команда `occ`, добавляющая недостающие индексы БД; типична после обновлений и для ускорения. _(главы 1, 2, 4, 6)_

**db:add-missing-columns** — команда `occ`, добавляющая недостающие столбцы в таблицы после миграций. _(главы 2, 4)_

**db:convert-filecache-bigint** — команда `occ` для перевода идентификаторов filecache в bigint на больших инсталляциях. _(глава 4)_

**pg_dump** — утилита PostgreSQL для создания дампа базы; основа ручного бэкапа Nextcloud. _(глава 5)_

**backup (бэкап)** — резервная копия БД, data directory и config; без проверки восстановлением не считается рабочим. _(глава 5)_

**restore drill** — учебное восстановление бэкапа на тестовом стенде, подтверждающее, что копия пригодна. _(главы 5, 10)_

**AIO backup** — штатный механизм резервного копирования Nextcloud AIO, запускаемый из AIO interface. _(глава 5)_

**offsite backup** — копия бэкапа вне сервера (например в облачном хранилище), переживающая полную потерю машины. _(глава 5)_

**AIO interface** — веб-панель mastercontainer (обычно порт 8080/8443) для управления контейнерами, обновлениями и бэкапами. _(главы 0, 2, 5)_

**Redis** — in-memory хранилище для кэша и file locking; ускоряет частые запросы, не доводя их до БД. _(глава 6)_

**file locking** — блокировка файлов при одновременном доступе; в Nextcloud реализуется через Redis. _(глава 6)_

**keyspace_hits / keyspace_misses** — счётчики попаданий и промахов кэша Redis; hits должны значительно превышать misses. _(глава 6)_

**background jobs (фоновые задачи)** — отложенные задачи Nextcloud (очистка, уведомления, индексация); запускаются в режимах AJAX, Webcron или System cron. _(глава 6)_

**AJAX (cron mode)** — режим фоновых задач, запускаемых при заходе пользователей; плох тем, что без посетителей задачи стоят. _(глава 6)_

**Webcron** — режим фоновых задач через внешний HTTP-вызов по расписанию. _(глава 6)_

**System cron** — рекомендуемый режим фоновых задач через системный cron сервера, независимый от посетителей. _(глава 6)_

**files:scan** — команда `occ`, пересканирующая файлы и обновляющая filecache; тяжёлая на больших инсталляциях. _(главы 6, 9)_

**reverse proxy** — Nginx перед Nextcloud, терминирующий HTTPS и проксирующий запросы в контейнер. _(главы 0, 7, 8)_

**Nginx** — веб-сервер/прокси на хосте, принимающий внешний HTTPS и направляющий трафик в AIO-контейнер. _(главы 0, 7, 8)_

**trusted_domains** — список доменов, с которых Nextcloud принимает запросы; чужой домен блокируется как «untrusted domain». _(глава 8)_

**trusted_proxies** — IP или подсети reverse proxy, которым Nextcloud доверяет реальный IP клиента из `X-Forwarded-For`. _(глава 8)_

**overwriteprotocol** — параметр, сообщающий Nextcloud, что снаружи HTTPS, чтобы ссылки генерировались как `https://`. _(глава 8)_

**brute force protection** — встроенная защита Nextcloud от перебора паролей; работает корректно только при верно настроенном `trusted_proxies`. _(глава 8)_

**2FA / MFA** — двухфакторная (многофакторная) аутентификация; рекомендуется для админских аккаунтов. _(глава 8)_

**config.php** — главный файл конфигурации Nextcloud с секретами, доменами и параметрами; не публикуется целиком, права обычно `640`. _(главы 0, 5, 8)_

**config:system:get / set** — команды `occ` для чтения и записи отдельных параметров системной конфигурации без открытия всего файла. _(главы 6, 8)_

**user:list / user:info** — команды `occ` для просмотра списка пользователей и подробностей конкретного аккаунта. _(глава 9)_

**quota (квота)** — лимит дискового пространства пользователя; задаётся через `occ user:setting ... files quota`. _(глава 9)_

**group (группа)** — объединение пользователей для выдачи доступа к шарам разом, а не каждому вручную. _(глава 9)_

**share (шара)** — предоставление доступа к файлу или папке пользователю, группе или по ссылке. _(главы 4, 9)_

**OC_PASS** — переменная окружения с паролем для неинтерактивных команд `occ user:add`/`resetpassword` (`--password-from-env`). _(глава 9)_

**runbook** — пошаговая инструкция действий при типовой аварии (например «Nextcloud не открывается»). _(главы 7, 10, приложение B)_

**502 Bad Gateway** — ошибка, когда Nginx жив, но апстрим-контейнер Nextcloud недоступен или указан не тот порт. _(глава 7)_

## Главная идея

Администрировать Nextcloud — значит понимать, из каких компонентов он состоит и как проверить каждый слой.

```text
Nginx
  -> Nextcloud app container
  -> PostgreSQL
  -> Redis
  -> data directory
  -> backup
  -> logs
```

Если ты знаешь только "сайт открывается", ты пользователь. Если знаешь, где логи, где данные, как восстановить бэкап и как работает `occ`, ты уже администратор.

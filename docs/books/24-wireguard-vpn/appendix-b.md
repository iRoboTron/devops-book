# Приложение B: Чеклист VPN

## Перед настройкой

- [ ] Есть второй SSH-сеанс.
- [ ] Есть доступ к консоли провайдера.
- [ ] Записаны текущие правила firewall.
- [ ] Понятно имя внешнего интерфейса.

## После настройки

- [ ] `sudo wg show` показывает свежий handshake.
- [ ] Клиент пингует `10.0.0.1`.
- [ ] UDP `51820` разрешён.
- [ ] SSH не потерян.
- [ ] У каждого устройства отдельный ключ.
- [ ] QR-коды и конфиги не лежат в публичных местах.
- [ ] Есть таблица peers.
- [ ] Есть процедура отзыва доступа.

## План внедрения

### За 1 день

- Поднять сервер и один клиент.
- Проверить handshake и ping.

### За 1 неделю

- Добавить телефон и ноутбук.
- Спрятать один сервис за VPN.

### За 1 месяц

- Описать runbook.
- Проверить отзыв тестового peer.
- Решить, нужен ли full tunnel.

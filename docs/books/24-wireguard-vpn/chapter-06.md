# Глава 6: Телефон, ноутбук и отзыв доступа

> **Цель:** добавить несколько устройств и понимать, как забрать доступ обратно.

---

## 6.1 Правило одного устройства

Каждому устройству — отдельный ключ и отдельный IP.

```text
10.0.0.2 -> phone
10.0.0.3 -> laptop
10.0.0.4 -> home-pc
```

Не используй один и тот же конфиг на телефоне и ноутбуке. Потом ты не поймёшь, кто подключается.

## 6.2 QR-код для телефона

```bash
sudo apt install qrencode
qrencode -t ansiutf8 < client-phone.conf
```

После выполнения команды в терминале появится ASCII-арт QR-код из символов Юникода — тёмные и светлые клетки, образующие квадратный паттерн. Открой приложение WireGuard на телефоне → «+» → «Сканировать QR-код» и поднеси камеру к экрану. Когда телефон распознает код, конфиг загрузится автоматически.

Если терминал слишком узкий или шрифт крупный, QR может не читаться. Уменьши шрифт терминала или используй `qrencode -t png -o /tmp/phone.png < client-phone.conf` и перенеси PNG-файл на телефон другим способом.

QR содержит приватный ключ. Его нельзя отправлять в общий чат или оставлять в истории терминала на чужом компьютере.

## 6.3 Добавить peer без полного перезапуска

```bash
sudo wg set wg0 peer <CLIENT_PUBLIC_KEY> allowed-ips 10.0.0.4/32
sudo wg show
```

```bash

  public key: 8J3vQkLmN2+XpR7tYwZ5aB1cDfGhIjKoMnOpQrSt4U=
  private key: (hidden)
  listening port: 51820

peer: mB4nRsT1qWoP9uYiL6jKxZ3cFvGhDeNaE8sCpA2lO=
  endpoint: 192.0.2.45:49182
  allowed ips: 10.0.0.2/32
  latest handshake: 2 minutes, 5 seconds ago
  transfer: 4.85 KiB received, 3.21 KiB sent

peer: pL7wVcX9yNqR2mFtS4kJ1bDhGzUoAeIi6nBsYjOp3Q=

```

Второй peer (home-pc) ещё не подключился — у него нет `endpoint` и нет `latest handshake`. Это нормально до первого подключения.

Но не забудь внести peer в `/etc/wireguard/wg0.conf`, иначе после перезапуска он исчезнет.

## 6.4 Отзыв доступа

Если телефон потерян:

1. Удали `[Peer]` телефона из `wg0.conf`.
2. Примени конфиг безопасно.
3. Проверь `sudo wg show`.
4. Если ключ мог быть украден, не используй его снова.
5. Создай новый конфиг для нового телефона.

---

> **Если что-то пошло не так: телефон подключился, но интернет не работает**
>
> Симптом: WireGuard на телефоне показывает «подключено» и handshake есть, но браузер не открывает сайты.
>
> Причина 1 — Full tunnel без NAT. Если в клиентском конфиге `AllowedIPs = 0.0.0.0/0` (весь трафик через VPN), на сервере должны быть включены:
> - IP forwarding: `sysctl net.ipv4.ip_forward` должен вернуть `1`.
> - NAT (маскарадинг). Добавь в `[Interface]` серверного конфига:
>   ```ini
>   PostUp = iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
>   PreDown = iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE
>   ```
>   Замени `eth0` на имя своего внешнего интерфейса.
>
> Причина 2 — Split tunnel, но маршрут не тот. Если `AllowedIPs = 10.0.0.0/24`, интернет и не должен идти через VPN — это задуманное поведение.
>
> Причина 3 — DNS. Добавь в `[Interface]` клиентского конфига: `DNS = 1.1.1.1`.

# Глоссарий

> Термины и выражения книги «Мониторинг с нуля — Prometheus, Grafana, Alertmanager». В скобках — главы, где термин вводится или активно используется.

---

**Мониторинг** — сбор, хранение и визуализация метрик системы плюс оповещения о проблемах. _(глава 0)_

**Метрика** — числовой показатель во времени (загрузка CPU, число запросов). _(главы 0, 2)_

**Time series (временной ряд)** — последовательность значений метрики с временными метками. _(глава 2)_

**Label (метка)** — пара ключ-значение, уточняющая метрику (`instance`, `job`). _(глава 2)_

**Prometheus** — система мониторинга, собирающая метрики по pull-модели и хранящая их как time series. _(глава 2)_

**Pull-модель / scrape** — Prometheus сам периодически опрашивает (`scrape`) цели по HTTP. _(глава 2)_

**Target (цель)** — endpoint, который Prometheus опрашивает за метриками. _(глава 2)_

**`scrape_interval`** — как часто Prometheus опрашивает цели. _(глава 2)_

**Exporter (экспортер)** — сервис, отдающий метрики в формате Prometheus по `/metrics`. _(главы 3, 7)_

**Node Exporter** — экспортер метрик сервера (CPU, память, диск, сеть). _(глава 3)_

**cAdvisor** — экспортер метрик Docker-контейнеров. _(глава 6)_

**Blackbox Exporter** — проверка доступности извне (HTTP/TCP/ICMP-пробы). _(глава 7)_

**PromQL** — язык запросов Prometheus к метрикам. _(глава 4)_

**Instant / range vector** — значение метрики в момент и за интервал времени. _(глава 4)_

**Counter** — монотонно растущий счётчик (число запросов, ошибок). _(главы 2, 4)_

**Gauge** — метрика, которая растёт и падает (температура, память). _(главы 2, 4)_

**Histogram / Summary** — распределение значений (например, времена ответа по бакетам). _(глава 4)_

**`rate()`** — функция PromQL: скорость роста counter за интервал. _(глава 4)_

**Grafana** — система дашбордов для визуализации метрик и логов. _(глава 5)_

**Dashboard / Panel** — набор панелей и отдельный график/таблица на нём. _(глава 5)_

**Datasource (источник данных)** — подключение Grafana к Prometheus/Loki и др. _(глава 5)_

**Variable (переменная)** — параметр дашборда для переключения instance/namespace. _(глава 5)_

**Alertmanager** — компонент маршрутизации и отправки оповещений по сработавшим алертам. _(глава 8)_

**Alert rule (правило алерта)** — условие на PromQL, при котором поднимается алерт. _(глава 8)_

**`for`** — выдержка времени, в течение которой условие должно держаться, прежде чем алерт «выстрелит». _(глава 8)_

**Routing / Receiver** — маршрутизация алертов по меткам к нужному каналу (Telegram, email). _(глава 8)_

**Grouping / Silence** — группировка похожих алертов и временное заглушение. _(глава 8)_

**Loki** — система агрегации логов, интегрированная с Grafana. _(глава 9)_

**Promtail** — агент, собирающий логи и отправляющий их в Loki. _(глава 9)_

**LogQL** — язык запросов к логам в Loki. _(глава 9)_

**Pushgateway** — приёмник метрик для коротких/batch-задач, которые нельзя опросить. _(глава 10)_

**Retention (срок хранения)** — как долго хранятся метрики. _(глава 11)_

**Remote write / long-term storage** — отправка метрик во внешнее долговременное хранилище (Thanos, Mimir, VictoriaMetrics). _(глава 11)_

**RED / USE** — методики выбора метрик: Rate/Errors/Duration для сервисов, Utilization/Saturation/Errors для ресурсов. _(глава 4)_

# Приложение E: Матрица совместимости инструментов

## Зачем это знать

Перед апгрейдом PostgreSQL проверьте совместимость всех инструментов, которые используются в вашей инфраструктуре. Несовместимая версия инструмента может привести к:
- невозможности создать бэкап;
- падению репликации;
- потере мониторинга.

## Матрица версий

| Инструмент | PG 14 | PG 15 | PG 16 | PG 17 |
|------------|-------|-------|-------|-------|
| pgBackRest | 2.45+ | 2.47+ | 2.49+ | 2.51+ |
| WAL-G | 2.0+ | 2.0+ | 3.0+ | 3.0+ |
| PgBouncer | 1.18+ | 1.20+ | 1.21+ | 1.23+ |
| Patroni | 3.0+ | 3.0+ | 3.2+ | 3.3+ |
| CloudNativePG | 1.21+ | 1.22+ | 1.23+ | 1.24+ |
| pg_stat_statements | встроен | встроен | встроен | встроен |
| postgres_exporter | 0.12+ | 0.13+ | 0.14+ | 0.15+ |

## Пояснения

**pgBackRest** — каждая новая версия PostgreSQL требует обновления pgBackRest. При апгрейде с PG 15 на 16 проверьте, что установлена версия 2.49+.

**WAL-G** — версия 3.0+ требуется для PG 16 и 17 из-за изменений в формате WAL.

**PgBouncer** — минимальная версия для PG 17 — 1.23+. Более старые версии могут не поддерживать новые типы аутентификации.

**Patroni** — сложный инструмент с собственным learning curve. При апгрейде PostgreSQL обновляйте Patroni в первую очередь.

**CloudNativePG** — оператор для Kubernetes. Версия 1.23+ поддерживает PG 16, версия 1.24+ — PG 17.

**pg_stat_statements** — встроен во все версии PostgreSQL 12+ (не требует отдельной установки).

**postgres_exporter** — при апгрейде PostgreSQL проверьте, что метрики не сломались. Некоторые системные представления меняются между мажорными версиями.

## Алгоритм проверки перед апгрейдом

1. Записать текущие версии всех инструментов.
2. Сверить с матрицей выше.
3. Обновить инструменты до минимально необходимых версий.
4. Протестировать на staging-копии production-данных.
5. Выполнить апгрейд PostgreSQL.
6. Проверить: бэкапы, репликацию, мониторинг, PgBouncer.

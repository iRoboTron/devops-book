# Глава 13: Личный communication playbook

> **Цель:** собрать собственный набор шаблонов, чтобы не придумывать структуру каждый раз.

---

## 13.1 Зачем нужен playbook

Когда ты устал, волнуешься или спешишь, мысль снова превращается в поток. Playbook помогает вернуться к структуре.

Это не документ для красоты. Это личная шпаргалка.

---

## 13.2 Структура

Создай `COMMUNICATION-PLAYBOOK.md`:

```markdown
# Мой инженерный communication playbook

## Сообщение о проблеме

## Вопрос о помощи

## Статус задачи

## Риск

## Сравнение вариантов

## README шаблон

## Runbook шаблон

## Incident report шаблон

## ТЗ для ИИ-агента

## Фразы для технического спора
```

---

## 13.3 Заполняй своими словами

Шаблон должен звучать естественно для тебя. Если формулировка кажется чужой, перепиши.

Например:

```text
Следующий статус: через 15 минут.
```

можно заменить на:

```text
Вернусь с обновлением до 15:30.
```

Смысл тот же: не оставлять людей в неопределённости.

---

## 13.4 Мини-набор на каждый день

Если не хочешь большой playbook, начни с 5 шаблонов:

1. проблема;
2. вопрос;
3. статус;
4. риск;
5. ТЗ для ИИ.

Этого уже достаточно, чтобы коммуникация стала заметно яснее.

---

## 13.5 Практика

Заполни playbook своими примерами. Не копируй все шаблоны бездумно. Каждый шаблон должен быть таким, чтобы ты реально мог им воспользоваться завтра.

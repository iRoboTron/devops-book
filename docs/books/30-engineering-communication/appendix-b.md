# Приложение B: Дальнейшее чтение

## The Pyramid Principle

Книга о структурировании мысли: сначала главный вывод, потом аргументы. Полезна для писем, отчётов и объяснений.

## Docs for Developers

Книга о технической документации: как писать документы для людей, которые будут реально ими пользоваться.

## Google Technical Writing Courses

Бесплатные курсы технического письма. Особенно полезны темы краткости, структуры и примеров.

## Atlassian Incident Management

Материалы про incident response: роли, статусы, communication, postmortem.

## Stripe Engineering Blog

Один из лучших публичных примеров blameless postmortem. Stripe публикует детальные разборы инцидентов на [stripe.com/blog/engineering](https://stripe.com/blog/engineering): хронология событий, root cause, что изменили в процессах. Полезно читать не только ради технического содержания, но и ради структуры — как профессионалы описывают проблему без обвинений и с конкретными выводами.

## Engineering blogs

Читайте инженерные блоги не только ради технологий, но и ради структуры:

- как они описывают проблему;
- как показывают ограничения;
- как объясняют решение;
- как признают tradeoffs.

## Как тренироваться

Не надо ждать идеального случая. Берите обычные сообщения и переписывайте:

| Материал | Упражнение |
|---|---|
| старый чат | переписать по шаблону проблемы |
| README | добавить запуск и проверку |
| спор в комментариях | отделить факт от мнения |
| задача для ИИ | добавить контекст и критерии проверки |
| инцидент | написать postmortem |

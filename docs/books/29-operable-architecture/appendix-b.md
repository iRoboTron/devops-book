# Приложение B: Ресурсы и дальнейшее чтение

## Building Microservices — Sam Newman

Полезна не как агитация за микросервисы, а как честное объяснение их цены: сеть, данные, границы, команды.

## Database Reliability Engineering

Книга про БД как важнейшую stateful-часть системы: backup, restore, миграции, эксплуатационные риски.

## 12factor.net

Классический набор принципов для приложений, которые удобно запускать в разных окружениях. Особенно полезны разделы config, logs, disposability.

## Expand/Contract pattern

Паттерн безопасных миграций: сначала расширить схему, затем перенести данные, потом убрать старое.

## Release It!

Книга про устойчивость приложений: timeout, circuit breaker, bulkhead, стабильность под реальной нагрузкой.

## Как читать

| Проблема | Что читать |
|---|---|
| думаешь о микросервисах | Building Microservices |
| страшно делать миграции | Database Reliability Engineering |
| настройки хаотичны | 12factor.net |
| релизы ломают прод | Expand/Contract + Release It! |
| внешние API валят сервис | Release It! |

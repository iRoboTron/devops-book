## Главная идея

Docker сделал контейнеры популярными. OCI превратил их в открытый стандарт. Теперь рантаймов много — и это хорошо.

```text
Раньше:
Docker = всё. Демон запущен → работает. Упал → ничего не работает.
Контейнеры от root → уязвимость = root на хосте.

Сейчас:
OCI-образ собрал Podman, запустил containerd, хранит Harbor.
Podman: нет демона + rootless + Docker-совместим + генерирует K8s YAML.
```

Если ты знаешь Docker — ты знаешь 90% Podman. Оставшиеся 10% — это и есть суть книги: безопасность через rootless, жизнь без демона, и мост в Kubernetes.

## OCI-стандарты

```text
OCI (Open Container Initiative) — https://opencontainers.org
│
├── Image Spec
│   Что: формат хранения образа (слои + манифест + конфиг)
│   Кто следует: Docker, Podman, containerd, buildah, kaniko
│   Ключевое: digest = sha256 хэш слоя, неизменяем
│
├── Runtime Spec
│   Что: как запускать контейнер (namespaces, cgroups, rootfs)
│   Кто реализует: runc, crun, youki, gVisor
│   Ключевое: config.json описывает что именно запускается
│
└── Distribution Spec
    Что: API реестра (push/pull/список тегов)
    Кто следует: все реестры (Docker Hub, Quay, Harbor, ...)
    Ключевое: /v2/<name>/manifests/<ref> — стандартный endpoint
```

## Родословная инструментов

```text
Docker (2013) ──────┬──► Docker Engine (daemon)
                    │       └── containerd (2016, вынесен как отдельный проект)
                    │               └── runc (OCI runtime)
                    │
                    └──► Podman (2018, Red Hat)
                              ├── fork-exec модель (без daemon)
                              ├── buildah (сборка образов)
                              └── skopeo (работа с реестрами)

Kubernetes (2014) ──┬──► Docker (до v1.24 через dockershim)
                    └──► CRI API (2016)
                              ├── containerd + cri plugin
                              └── CRI-O (только K8s)
```

## Что когда использовать

```text
Задача                              Инструмент
────────────────────────────────────────────────────────────────────
Локальная разработка                podman run / podman-compose
Сборка образа (стандарт)            podman build (использует buildah)
Сборка образа (CI rootless)         buildah bud
Сборка образа (K8s)                 kaniko или buildah в Tekton
Копирование между реестрами         skopeo copy
Инспекция образа без pull           skopeo inspect
Зеркало реестра                     skopeo sync
Systemd автозапуск                  Quadlet (.container файлы)
Диагностика K8s node                crictl
Compose (с Podman)                  podman-compose
Compose (с Docker)                  docker compose
Production оркестрация              Kubernetes
Dev на macOS/Windows                Podman Desktop / Podman Machine
Self-hosted реестр (prod)           Harbor
Self-hosted реестр (тест)           Registry:2
```

| Инструмент | Когда появилось | Где используется |
|-----------|----------------|-----------------|
| Docker | 2013 | Везде (legacy и dev) |

| containerd | 2016 | Docker, K8s |

| pasta (сеть) | 2023 (Podman 5+) | rootless сеть |
